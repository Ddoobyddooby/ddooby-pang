# 디자인 테마 + 연쇄 이펙트 설계

> 상태: 승인됨 (2026-10-29) · 관련 태스크: `docs/TASKS.md`의 "디자인" 묶음 (D-01 ~ D-11)
> 시안: `.superpowers/brainstorm/` (git에는 올리지 않음)

---

## 1. 목적

1주차에 로직과 기본 화면이 돌아가기 시작했다. 경쟁 모드와 스토리 모드가 **공통으로 쓰는 화면 바탕**(테마, 블록 모양, 연쇄 이펙트)을 지금 정해 두고, 이후 모드 화면은 이걸 가져다 쓴다.

- 주 사용자: 조카 (아이). 밝고 아기자기해야 한다
- 캔디크러시를 벤치마크했지만 **똑같아 보이지 않아야** 한다
- 실기기(Android) 60fps 목표(W4-10)를 해치지 않아야 한다

## 2. 결정 사항

| 항목 | 결정 | 고려한 대안 |
|---|---|---|
| 테마 | **달콤 디저트** | 숲속 동물, 바다, 우주 |
| 배경 | **솜사탕 하늘**: 하늘색 → 분홍 그라데이션, 흘러가는 구름, 반짝이는 작은 별 | 딸기우유 체크 식탁보, 사탕 나라 언덕 (캔디크러시 느낌이 강해서 제외) |
| 보드판 | **웨이퍼**: 베이지 판 + 진한 테두리 + 가로 결, 안쪽은 크림색 | 반투명 흰 판, 쿠키 접시 |
| 블록 | **말랑 친구들**: 지금의 색 + 모양(원, 둥근 사각형, 다이아몬드, 삼각형, 육각형, 별)을 유지하고 **눈·볼터치·입**을 그린다 | 젤리 사탕(캔디크러시와 비슷), 디저트 아이콘 |
| 표정 | 3종: **평소**, 터질 때 **`><`**, 신날 때 **`^^`** | |
| 그래픽 방식 | **코드로 그린다**. 시작할 때 텍스처로 한 번 구워서 재사용 | 무료 에셋 PNG, 혼합 |
| 글꼴 | **Jua** (OFL). 파일을 프로젝트에 포함해 오프라인에서도 동작 | Google Fonts 원격 로드 (APK 오프라인에서 실패) |
| 이펙트 | 조각 파티클, 칭찬 문구, 화면 흔들림, 말랑 움직임 **모두** | |

색은 시안 기준값을 `THEME`에 둔다 (블록 채움 / 테두리):

| Color | 모양 | 채움 | 테두리 |
|---|---|---|---|
| 0 빨강 | 원 | `#ff7b88` | `#e45a6b` |
| 1 노랑 | 둥근 사각형 | `#ffdb5e` | `#e8b622` |
| 2 초록 | 다이아몬드 | `#6be0a4` | `#34b877` |
| 3 파랑 | 둥근 삼각형 | `#78b6ff` | `#3f88e6` |
| 4 보라 | 육각형 | `#bc8af2` | `#8f55d6` |
| 5 주황 | 별 | `#ffab69` | `#ee8031` |

## 3. 연쇄 단계별 연출

연쇄 단계 = core `match` 이벤트의 `cascade + 1` (스왑으로 생긴 첫 매치가 1단계).

| 단계 | 조각 파티클 | 칭찬 문구 | 화면 흔들림 | 남은 블록 `^^` |
|---|---|---|---|---|
| 1 | 하트, 블록당 1~2개 | 없음 | 없음 | 없음 |
| 2 | 하트 2배 + 별 | `이안팡!` | 없음 | 없음 |
| 3 | 더 많이 | `이서팡!` (더 크게) | 약하게 | 잠깐 웃음 |
| 4 | 더 많이 | `보라팡!!` | 강하게 | 잠깐 웃음 |
| 5 이상 | 최대 (상한 `FX.maxParticles`) | `사랑해!!!` | 강하게 | 잠깐 웃음 |

- 칭찬 문구는 **`config.FX.praise` 표 하나**로 관리한다. 사용자가 언제든 바꿀 수 있어야 한다 (시안 단계의 임시 문구)
- 5단계 이상은 5단계 연출을 그대로 쓴다
- 단계와 관계없이 항상: 터지기 직전 `><` 표정 → 사라짐, 낙하·리필 착지 때 말랑하게 눌림, 스왑할 때 살짝 커짐

## 4. 구조

```
src/
├── config.ts               THEME(색) · FX(단계별 세기, 문구, 상한) · ANIM(말랑·터짐 시간)
└── view/
    ├── theme/
    │   ├── textures.ts     블록 18장(6색 × 3표정) + 특수 표시 + 파티클(하트·별) 텍스처 생성
    │   ├── Background.ts   하늘 그라데이션, 구름, 별
    │   └── BoardFrame.ts   웨이퍼 보드판
    ├── fx/
    │   ├── fxLevels.ts     순수 함수: 연쇄 단계 → 연출 세기 (Phaser 없음, 테스트 대상)
    │   └── FxDirector.ts   파티클 · 문구 · 흔들림 · 웃음 재생
    ├── BlockSprite.ts      텍스처 이미지 기반. setFace(), squish() 등
    └── BoardView.ts        이벤트 재생 + 알림(hooks)만. 이펙트 코드는 넣지 않는다
public/fonts/Jua-Regular.ttf
```

### 4.1 경계

- **core는 바뀌지 않는다.** 연출에 필요한 정보(연쇄 단계, 제거된 칸, 착지한 블록)는 이미 이벤트에 들어 있다
- **BoardView → FxDirector는 알림만** 보낸다. BoardView는 어떤 연출이 나오는지 모른다
  ```ts
  interface BoardViewHooks {
    onMatch?(level: number, removed: { at: Pos; color: Color | null }[]): void;
    onLand?(ids: number[]): void;
  }
  ```
- **연출은 재생을 기다리게 하지 않는다.** `play(steps)`의 완료 시점과 입력 잠금 시간은 그대로다. 터지기 전 `><` 표정만 기존 remove 애니메이션 안에서 처리한다
- **FxDirector는 모드를 모른다.** 경쟁 / 스토리 모드 모두 GameScene에서 같은 방식으로 연결한다

### 4.2 블록 텍스처

- BootScene에서 Phaser `Graphics`로 그려 `generateTexture`로 저장한다. 키: `block-{color}-{face}` (`face` = `normal` / `squint` / `happy`), `special-{kind}`, `fx-heart`, `fx-star`
- 컬러 블록(색 없음)은 무지개 원 + 얼굴로 그린다
- 고해상도 화면에서 흐려지지 않도록 칸 크기보다 크게 그려서 축소해 쓴다

### 4.3 글꼴

- `public/fonts/Jua-Regular.ttf` + `index.html`의 `@font-face`
- BootScene에서 `document.fonts.load()`가 끝난 뒤 GameScene을 시작한다 (Phaser 텍스트가 기본 글꼴로 먼저 그려지는 것 방지)
- 라이선스 파일(`OFL.txt`)을 같이 둔다

## 5. 성능

- 블록은 이미지라 프레임마다 다시 그리지 않는다
- 파티클은 Phaser ParticleEmitter를 재사용하고, 한 번에 나오는 조각 수를 `FX.maxParticles`로 제한한다
- 구름·별 애니메이션은 트윈 몇 개로 끝낸다 (프레임마다 계산하지 않음)

## 6. 테스트와 확인

| 대상 | 방법 |
|---|---|
| `fxLevels` | 🧪 연쇄 1~10단계: 조각 수 증가(상한 이하), 문구 선택(1단계 없음, 5단계 이상은 5단계), 흔들림·웃음 시작 단계 |
| `FX.praise` | 🧪 2~5단계 문구가 모두 있다 |
| 기존 동작 | 🧪 `npm test` 전부 통과. 퍼즈 테스트는 core라 영향 없음 |
| 화면 | 👀 `?demo`로 연쇄 연출 확인, 개발 모드에서 **키보드 2~5**로 그 단계 연출 미리보기, 휴대폰 브라우저에서 끊김 확인 |
| 화면 = 상태 | 👀 개발 모드 `view ≠ board` 에러 0 (BlockSprite를 바꿔도 위치 추적은 같다) |
