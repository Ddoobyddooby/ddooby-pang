전체 분위기: 어떤 화면이 제일 마음에 드세요?

배경 · 보드 판 · 타이틀 느낌을 비교하는 시안입니다. 블록은 세 시안 모두 같고(사탕 모양 1차안), 다음 화면에서 따로 고릅니다.

A. 솜사탕 하늘

하늘색→분홍 그라데이션, 둥실 구름과 작은 별. 보드는 반투명 흰 판. 가장 밝고 깔끔하고, 블록이 잘 보인다

B. 딸기우유 테이블

분홍 체크 식탁보 + 물결 리본 HUD, 보드는 쿠키 접시. 가장 '디저트 가게' 느낌, 배경 무늬가 블록과 겹쳐 보일 수 있음

C. 사탕 나라 언덕

노랑→분홍 하늘, 민트·딸기 언덕과 롤리팝 나무, 보드는 웨이퍼 판. 이야기(스토리 모드 맵)로 확장하기 좋음

타이틀 글꼴은 세 시안 모두 둥글고 귀여운 무료 한글 글꼴 Jua(Google Fonts)를 썼습니다. 섞고 싶은 조합(예: "A 배경 + C 보드")이 있으면 터미널에 적어주세요.
