|---|---|---|---|
| 2026-11-02 | (사용자를 거쳐 전달) | - | "특수블록이 다른 특수블록에 의해서 터질 때 그냥 일반블록처럼 판정돼서 터지는 것 같음 (특수효과 유지 희망)". 가로줄이 터질 때 그 줄에 세로줄 블록이 있으면 세로로도 없어져야 한다는 뜻 → F1 |

- 목소리(이안팡·이서팡·보라팡·사랑해)가 나올 때 반응
- 어디서 그만두는지, 다시 하자고 하는지, 경쟁 60초와 스토리 중 어느 쪽을 고르는지
