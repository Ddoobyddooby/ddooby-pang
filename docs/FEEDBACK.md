# FEEDBACK

플레이해 본 사람의 반응과 리뷰 의견을 모은다. 고칠 것으로 정해지면 `docs/TASKS.md`에 태스크로 옮기고 여기에는 태스크 ID를 적는다.

- 상태: `열림`(아직 안 정함) · `→ W?-??`(태스크로 옮김) · `보류`(v0.2 이후) · `안 함`
- 우선순위: **높음**(아이가 막히거나 헷갈림) · 중간(재미·편의) · 낮음(다듬기)

## 1. 조카 시범 플레이 (W4-11)

날짜, 기기, 해 본 모드를 적고, 본 그대로 적는다 (해석은 2절에서).

| 날짜 | 기기 | 모드·스테이지 | 본 것 / 한 말 |
|---|---|---|---|
| | | | |

**볼 것** (이걸 다 묻지 말고, 놀 때 보이는 것만 적는다)

- 처음 화면에서 설명 없이 무엇을 누르는지, 블록을 밀어서 바꾸는 걸 혼자 알아내는지
- 스토리 미션(색 모으기, 점수)을 이해하는지, 지는 이유를 아는지
- 목소리(이안팡·이서팡·보라팡·사랑해)가 나올 때 반응
- 어디서 그만두는지, 다시 하자고 하는지, 경쟁 60초와 스토리 중 어느 쪽을 고르는지
- 손가락이 작아서 잘못 누르는 블록이 있는지

## 2. 리뷰 의견 (메인 세션, 2026-11-01)

v0.1을 390×844 화면으로 다시 보고, 스테이지 데이터(`public/stages/story.json`)와 설정을 읽고 적었다. 시범 플레이 전에 미리 고치자는 것은 아니다. 조카 반응을 보고 맞는 것만 고른다.
